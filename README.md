# 🫧 Aero Smash

Juego incremental con estética **Frutiger Aero**: rompe orbes, mejora tus habilidades y viaja de la noche al día a lo largo de 1000 niveles (y después, infinito).

**▶ Jugar:** https://sauremk.github.io/aero-smash/

## Instalar en el celular
- **Android (Chrome):** abre el enlace → menú ⋮ → *Instalar app* / *Agregar a pantalla principal*.
- **iPhone (Safari):** abre el enlace → botón Compartir → *Agregar a inicio*.

Funciona sin internet después de la primera visita. El progreso se guarda en el propio dispositivo.

## Archivos
- `index.html` — el juego completo
- `manifest.webmanifest`, `sw.js`, `icons/` — lo que lo convierte en app instalable (PWA)
